🛡️ Cyber Security AI

Cyber Security AI is an educational defensive cybersecurity platform designed to combine AI assistance with practical security-analysis tools. The project focuses on security awareness, basic risk analysis and safe defensive practices.

🎯 Project Objective

The goal is to provide users with an easy-to-use security center where they can learn about cybersecurity and perform basic defensive checks from one interface.
